## 0. 事实基础（已验证）

**SAM 3.1 不是纯换 checkpoint（推翻最初假设）**
- 状态字典 diff（`ckpt_diff.py` / `ckpt_value_diff.py`，job tmp）：
  - 共 1130 个 `detector.*` 公共张量，0 个形状不匹配；**1093 个值已变**（top rel 2–4.6%）→ 检测器真·重训过。
  - 3.1 检测器**删除 `convs.3`**（3.0 里是 scale-1.0 neck FPN 主 mask 路径块），**新增 `interactive_convs`**（36 个）。
  - 若用 3.0 代码 + 3.1 权重：`convs.3` 保持随机初始化 → mask 质量不可控。**结论：必须换 3.1 代码。**
- 已从镜像（ghfast.top tarball）落地 3.1 代码树 `sam31/`（commit 660a5e9，含 `RELEASE_SAM3p1.md`），
  `build_sam3_image_model(...)` 签名与 3.0 完全一致，`download_ckpt_from_hf` 原生认识 `facebook/sam3.1`。
- Multiplex（共享显存多目标视频跟踪，128 目标 ~7× 提速）是 **video-only** 特性；我们的生产路径是
  非交互 image model（`enable_inst_interactivity=False`），不受影响也不受益。
- 依赖集与 3.0 相同（`sam31/pyproject.toml`：timm/numpy<2/tqdm/ftfy/regex/iopath…），无新运行时依赖。

**MapAnything 形态**
- 入口：`MapAnything.from_pretrained(<本地目录>)`；`load_images(paths)`（fixed_mapping，按平均宽高比选
  RESOLUTION_MAPPINGS[518] 桶：1:1→518×518，4:3→518×392，16:9→518×294，Lanczos+居中裁剪）；
  `model.infer(views, memory_efficient_inference=True, minibatch_size=1, use_amp=True,
  amp_dtype="bf16", apply_mask=True, mask_edges=True)`。
- 输出：`camera_poses` 为 OpenCV **c2w**（需 `inv()` 转 w2c）；`depth_z` 米制；`pts3d` 世界系（view-0 锚定）米制；
  `intrinsics` 3×3 像素单位，**内部分辨率**（无 upscale 回原图的映射提供）；
  `conf` 头部原样输出（不激活，越高越好；MapAnything 自己只做 percentile 相对过滤）。
- fd 数据集图像实测 3024×4032（3:4 竖图）→ 518 桶必含**居中裁剪** → affine 含平移分量。
- 根 venv（torch 2.7.1+cu126, numpy 1.26.4）缺 4 个依赖：`uniception==0.1.7`（硬 import）、
  `hydra-core`、`python-box`、`orjson`（可跳过 rerun-sdk/tensorboard）。

**消费端契约（predictions.npz + matching 阶段）**
- pi3 写入 `conf` 前过 `torch.sigmoid`，默认阈值 0.05（utils/config.py:274）；da3 原样写入，注释范围 [1,6]，阈值 1.5（:461）。
  MapAnything 适配层**原样写入** conf（语义与 da3 同类），阈值分支见 §2.4。
- pi3x 的 affine 消费分支是**纯缩放**（utils/matching_algorithms.py:444-454），不够裁剪场景；
  da3 分支读 `source_to_processed_affine`（完整 (2,3)）+ `source_image_sizes`（schema v3）→ MapAnything 复用 da3 式完整 affine 路径。
- `build_transforms`（utils/transforms.py:568）按 `model_type` 分发 vggt/pi3/da3 → 需新增 mapanything 分支，复现 fixed_mapping 的 resize+crop，保证 SAM3 prompt 坐标映射一致。
- **SAM3 mask 磁盘缓存（v2）的 key 不含 checkpoint 身份**（`_INFERENCE_CONTRACT` 固定 6 字段：
  api/threshold/image_size/max_batch_size/max_dets_per_query/clip_to_bbox）→ 直接换 3.1 checkpoint 会
  **静默命中 3.0 的旧 mask**。3.1 臂必须换 cache root，且目录名必须仍为 `v2`（`sam3_mask_cache.py:158` 校验）。

## 1. SAM 3.1 接入设计

### 1.1 代码根可切换（新增，默认不变）
- `config.yaml` `inference` 新增 `sam3_code_root: ""`（默认空 = 现行为 `sam3/`）。
- `utils/sam3_utils.py` `_ensure_sam3_in_path()` 尊重覆盖值：非空时插入 `<root>`（即 `sam31/`）到
  `sys.path[0]` 并校验 `<root>/sam3/__init__.py` 存在；默认行为逐字节不变。
- 单进程单根假设：一次运行只可能有一个根（A/B 各臂是独立进程），无中途切换需求。
- checkpoint 路径沿用现有 `inference.sam3_checkpoint_path`，指向
  `/home/xingyu/.cache/modelscope/models/facebook--sam3.1/snapshots/master/sam3.1_multiplex.pt`。
  checkpoint SHA 摘要已有（`checkpoint_sha256`，sam3_utils.py:236），仅日志用途。

### 1.2 冒烟门槛
- 用 sam31 代码 + 3.1 checkpoint 构建 image model，**打印 `load_state_dict` 的 missing/unexpected keys**：
  预期 missing 为空（3.1 neck 不再构建 `convs.3`，新增 `interactive_convs` 由权重覆盖）。
- 真模型跑 `sam3_masks_self_exemplar` 一帧 fd 图 + 1 个真实 bbox，mask 非空且覆盖 bbox 中部。

### 1.3 风险与对策
- 风险：3.1 检测器重训后行为漂移 → 这正是 A/B 要测的，不预设方向。
- 风险：mask cache root 校验要求名字为 `v2` → 用 `Output/sam3_mask_cache_sam31/v2` 这类目录。
- 不改 `sam3/` 目录本体（git 里还压着别人 staged 的删除，避免纠缠回滚）。

## 2. MapAnything backend 设计

### 2.1 隔离方案取舍
| 方案 | 说明 | 取舍 |
|---|---|---|
| **A. 根 venv 加装（推荐）** | `uv pip install uniception==0.1.7 hydra-core python-box orjson` 进根 venv | 与 pi3x 同为 in-process，改动小；先 `--dry-run` 确认不升/降现有包（torch/numpy 冻结即通过） |
| B. subprocess 隔离（da3 先例） | 自建 venv + runner | 依赖冲突时的退路；成本高（复制 8GB venv 级依赖），仅在 A 冲突时启用 |

### 2.2 适配器（新文件 `src/mapanything_3d_reconstructor.py`，pi3x 模板）
- `@register_reconstructor("mapanything")` + `src/__init__.py` 导入；不改 registry 机制。
- 流程：sys.path 注入 `map-anything/` → `from_pretrained(modelscope 快照目录)` →
  `load_images(路径表)` → `infer(..., memory_efficient_inference=True, minibatch_size=1, use_amp=True, amp_dtype="bf16", apply_mask=True, mask_edges=True)`。
- npz 写出（沿用 pi3 writer 的 `_save_predictions_npz` 通道，source_model="mapanything"）：
  - `world_points` ← `pts3d`（世界系，米制；转 (N,H,W,3) f32）
  - `depth` ← `depth_z`（米制）
  - `extrinsic` ← `torch.linalg.inv(camera_poses)`（c2w→w2c，(N,3,4)|(N,4,4)）
  - `intrinsic` ← `intrinsics`（内部分辨率像素单位，+0.5 网格约定按消费端既有处理）
  - `conf`/`depth_conf`/`world_points_conf` ← `conf` **原样**
  - `image_ids`、`images`（uint8，内部分辨率）
  - `source_image_sizes`（原始 W,H）+ `source_to_processed_affine`（完整 (2,3)：resize 缩放 + 居中裁剪平移）+
    `cache_schema_version=3`、`is_metric=1`、`source_model="mapanything"`
  - `local_points` 可由 w2c 反投（或省略，消费端不强制）——按 pi3x 做法定

### 2.3 消费端与 CLI 接线（全部加法）
- `utils/matching_algorithms.py` 消费门：`("pi3","pi3x","da3")` → 加入 `"mapanything"`；完整 affine 分支
  （`bind_da3_transforms_from_cache` 路径）对 mapanything 同样生效（门与分支解耦，逻辑上 mapanything 走 da3 式）。
- `utils/transforms.py` `build_transforms` 新增 `model_type == "mapanything"` 分支：复现 fixed_mapping
  （平均宽高比选桶 + Lanczos resize + 居中裁剪），保证与 writer 侧逐像素一致；`utils/config.py`
  `model_type` 属性与 `transform_kwargs` 增加 mapanything 映射（无额外 kwargs，桶逻辑自包含）。
- `main.py` CLI choices（`--recon_backend`/`--match_backend`，main.py:1395-1414 附近）加 `"mapanything"`。
- `utils/sku_matching_system.py:79` 的 backend 门同步加入。
- `scripts/3d/evaluation/batch_accuracy_evaluation.sh` case 语句加 mapanything 分支（评测脚本对齐）。
- `_validate_config` 白名单 `("vggt","pi3","pi3x","da3")` 加 `"mapanything"`。

### 2.4 阈值分支（`utils/config.py` `for_3d_mapping`）
- 几何：MapAnything 是**米制**（绝对深度）→ 沿用 da3 分支几何（min_depth 0.3 / max_depth 8.0 /
  max_3d_distance 0.5 / depth_consistency_threshold 0.3）。
- 置信度：conf 原样、范围未知 → 冒烟时看经验分布（分位数），一次性定档（类比 da3 注释"conf[1,6]，1.5 过滤低端噪声"
  的下四分位思路），**全臂固定不改**，报告里披露取值依据。不引入逐数据集调参（避免不公平 A/B）。

### 2.5 风险与对策
- 风险：根 venv 装依赖引发解析漂移 → 先 `uv pip install --dry-run` 审查；torch/numpy 版本被触碰即转方案 B。
- 风险：xformers 缺失（uniception 可选依赖）→ memory_efficient 路径有 SDPA 回退；冒烟验证。
- 风险：bf16 在 GPU2（24G）算力支持 → Ampere+ 均可；冒烟验证。
- 风险：内部分辨率与 SAM3 prompt 映射不一致 → affine 逐像素等价校验（见冒烟）。

## 3. A/B 评测协议

- 数据：**fd4–fd8**（与 pi3x-vs-da3 先例一致，docs/accuracy_da3_vs_pi3x.md），GT = picture_mapping_benchmark.csv，
  指标 = accuracy_annotation.py 产出的 micro-F1 聚合。
- 环境：`CUDA_VISIBLE_DEVICES=2`（24G 空闲）；除被测因子外配置全同。
- 臂设计（单因子）：
  1. **baseline（da3 + sam3.pt）**：直接引用先例文档数字（fd4-8 micro-F1 85.0%），不重跑。
  2. **+SAM3.1**：backend 保持 da3（复用 da3_cache，重建阶段零成本），仅 `sam3_checkpoint_path` → 3.1 +
     `sam3_code_root` → `sam31/` + `sam3_mask_cache_root` → `Output/sam3_mask_cache_sam31/v2`（防旧 mask 命中）。
  3. **+MapAnything**：backend=mapanything（全新重建缓存 mapanything_cache/），SAM3 保持 sam3.pt。
  4. **（条件）combo**：仅当 2、3 都 ≥ 持平时跑；任一明显回退则归因后停。
- 公平性核查：跑前确认各臂 mask cache 目录为空/独立；跑后 spot-check `run_*.log` 里 checkpoint 路径与
  code root 生效；MapAnything 臂 conf 阈值固定不随数据集变。
- 归因：除 F1 外记录 P/R、每数据集差值、MapAnything 重建耗时（vs da3）。
- 冒烟先行：任一臂冒烟不过不进 A/B。
