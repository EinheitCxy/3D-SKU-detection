## 项目事实

- 当前首次打开 viewer 是过滤后的全景点云，SKU 进入路径为 global ID dropdown/Prev/Next 或 Pick Mode。
- 当前选择面板显示 image/object ID 和 active/removed，但不显示源图、bbox、mask、面积轮廓或 provenance；默认重建查找也未自动接入 DA3。
- footprint 已有 accepted/rejected、value/null、逐 ID OBB、union GeoJSON、PNG 和 provenance/shadow evidence。
- 未跟踪 `facing_area` 仍是候选方向最大投影凸包，报告缺少 status、输入摘要、轮廓坐标和所选法向，只能标为实验性结果，不能直接作为可信 KPI。

## 三种方案

### A：3D 审查驾驶舱

中性 RGB 全景 + 顶部运行状态；选中 SKU 后高亮其点云、淡化其他对象；右侧显示 front-facing area、footprint、源图证据。沿用 Viser，成本中等；应验证 3D-first 是否降低任务时间和误选率。

### B：2D/3D 联动证据检查器

首次显示源图 contact sheet 与 global ID 列表；选中 bbox 后展开同一 ID 的全部观测，同时在 3D 视窗定位点云、相机和轮廓。证据路径最短，但需要 bbox/mask/affine 联动。

### C：双指标看板 + 按需 3D

首屏显示运行状态、SKU 覆盖率、front-facing area 卡和 ground footprint 卡；通过表格或俯视图进入 SKU，3D/源图证据延迟加载。首屏最快，适合管理汇报，但容易诱发 KPI 过度信任。

## 显示规则

- 青色竖直平面：front-facing projected area / per SKU。
- 琥珀色水平平面：ground footprint OBB union / stack。
- 两种面积不得同色、共用排行榜或相加。
- 固定证据链：`value -> metric/run/status -> polygon/points -> global_id -> image/object/bbox/mask -> source image digest`。
- 必显 dataset、run/generation、metric、unit、source model、cache schema 和 status；shadow evidence 与 formal status 分开。
- `null` 不得渲染为 `0 m²`。
