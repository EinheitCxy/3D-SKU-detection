# 候选 3：固定预算的覆盖代理优先采样

已实现 `coverage.select(data, budget)`。返回原始 `(frame,y,x)` 网格的 C-order `int64` 索引、全为 `(4,4)` 的 `float32` scales，以及可序列化统计。正式输入预算仍为 **217049**；观测点、深度、相机、源帧与四采样纹理可见性规则均由原数据和既有导出器保留。本模块不融合、平均或制造点，不增加 confidence 筛除门槛。

本轮仅实现并运行 focused tests，**未运行 29 帧全场景，也未证明覆盖或视觉收益**。空间单元占用始终称为 coverage proxy，不能代替独立 raycast 的有效深度支撑覆盖。

## 方法与固定参数

1. 按帧处理全部已有 `valid` 观测。用 `cross(u,v)` 的单位法向，朝原相机定向；不修改原切向量。
2. 覆盖单元键包含 world xyz 的 `4*spacing` 格、**96** 个有符号 cube-map 法向 bin（6 个面 × 4 × 4 斜率 bin），以及点沿 bin 中心法向投影的 `1*spacing` 薄层。不同正反面/侧面由有符号法向区分，较远的平行表面由薄层区分；所有输出仍是实际原始观测。它不是无约束 voxel averaging，也不执行表面融合。
3. 每个单元内先从各 `2*spacing` 子单元取质量最高的代表，再轮转第二个代表。这样同一表面增加重复视图不会直接提高它的首轮预算。
4. 跨单元按 `slot / (0.35 + 0.65 * best_representative_quality)` 排优先级。高质量单元可在极低质量孤立单元之前获得第二个名额；不存在因 bin 新颖就无条件保留所有孤立点的规则。质量由以下因素组成：
   - 50%：原始 scale-4、radius-1.05 圆盘的 8 个顶点在原源帧内通过已有 `valid` 和 `max(2*spacing, 0.005*Z)` 深度支撑的比例。
   - 25%：原源网格上下左右四邻点的局部平面支撑比例（绝对法向夹角 ≤35°、点到候选切平面距离 ≤`spacing`）。这只降低缺少局部连贯性的点的优先级。
   - 15%：原源视线与法向的 cosine。
   - 10%：有界 confidence，即 `c/(1+c)`；不是全局 confidence top-K。
   - 整体再乘 `sqrt(min(1, 2*spacing / max(norm(u),norm(v))))`，降低异常宽圆盘作为代表的优先级，但不改变实际 scale 或删掉候选资格。
5. 精确截断到预算；优先级完全相同时，均匀取排序后空间单元中的位置，避免只取空间顺序的一端。输出按原 flat index 排序，源帧与 xy 可直接恢复。

统计包含有效观测数、每帧选择数、固定 scale 分布、全部/已选/baseline 的覆盖代理单元数、轮转 slot 分布、已选质量分位数、源图支撑诊断及 feature/selection wall time。源图圆盘顶点支撑只是采样质量信号，不是实际有纹理三角面比例。

## 验证 receipt

运行命令：

```bash
UV_CACHE_DIR=/tmp/codex-uv-surfel-coverage OPENBLAS_NUM_THREADS=8 OMP_NUM_THREADS=8 MKL_NUM_THREADS=8 uv run --no-sync python -m pytest perf/surfel_coverage/test_coverage.py -q
```

结果：**3 passed in 1.13s**，退出码 0。

- 262144 个合成网格观测中包含无效小块，选择恰好 **217049** 个唯一有效原索引，scale 全为 4，原始点坐标未被修改，每帧统计与预算一致。
- 两块同等物理面积的平面，第一块重复 8 帧、第二块仅 1 帧。基线 stride-4 总预算 2304，其中稀有面只有 256；候选稀有面分配通过 `>=3×256` 且占总预算 35%–65% 的断言，克服了基线 8:1 的视图数偏置。这个案例只验证预算分配行为，不能推出真实场景视觉改善。
- 请求超过已有有效观测数的预算时明确报错。

实现按帧构造质量信号，全局使用 O(N) 紧凑键/索引和 O(N log N) 排序，不构建 N×N 或 N×帧数距离矩阵。**全场景少于 2 分钟与内存峰值尚未实测**；上面的 pytest 总耗时不作为全场景性能结论。

## 限制与后续评价边界

- 法向与空间 bin 边界会把近似相同表面拆开；接近薄层宽度的平行层仍可能分到同一代理单元。这影响预算分配，不会平均或移动几何。
- 局部连贯、源图自洽的深度离群面仍可能获得新单元预算；没有语义实例信息，也没有把多视图一致性当作已验证事实。
- 固定 scale 4 的圆盘仍可能跨边界。源图支撑与宽切向量惩罚只能降低这类代表的优先级；不能保证消除 bleeding。边缘表面也可能因低支撑而被分配较少预算。
- 原始纹理可见性 gate 仍决定三角面是否贴图。灰面比例降低并不等价于新增有效覆盖。
- 最终判断依赖 coordinator 的原相机 raycast，以及同步 front、side60、close-up、source-color 视图；当前实现尚无实际收益或生产可用性的结论。
